# Mr. Limo Booking

مرحباً بك في **Mr. Limo Booking** - موقع لحجز خدمات الليموزين الفاخرة.

## نظرة عامة

هذا المشروع عبارة عن موقع ويب لخدمات حجز الليموزين الفاخرة. يتميز الموقع بتصميم عصري وسهل الاستخدام، مع دعم كامل للغة العربية والخطوط المخصصة.

## الميزات

- ✨ تصميم عصري وجذاب
- 🚗 عرض خدمات الليموزين المتنوعة
- 📱 تصميم متجاوب (Responsive) يعمل على جميع الأجهزة
- 🌐 دعم كامل للغة العربية (RTL)
- 🎨 استخدام الخطوط المخصصة (TechmimArabic و ClashDisplay)
- 📝 نموذج حجز تفاعلي
- 🔄 تنقل سلس بين الأقسام

## الأقسام

### 1. الصفحة الرئيسية (Hero)
قسم ترحيبي بتصميم جذاب يحتوي على عنوان رئيسي وزر دعوة للإجراء.

### 2. خدماتنا
عرض الخدمات المتاحة:
- نقل المطار
- مناسبات خاصة
- جولات المدينة
- خدمات الأعمال

### 3. أسطولنا
عرض أنواع السيارات المتاحة:
- سيدان فاخرة (3 ركاب)
- SUV فاخرة (6 ركاب)
- ليموزين ممتدة (8-10 ركاب)

### 4. احجز الآن
نموذج حجز تفاعلي يحتوي على:
- معلومات العميل (الاسم، الهاتف، البريد الإلكتروني)
- تفاصيل الرحلة (الاستلام، الوجهة، التاريخ، الوقت)
- اختيار نوع السيارة

### 5. اتصل بنا
معلومات التواصل:
- رقم الهاتف
- البريد الإلكتروني
- العنوان

## كيفية الاستخدام

### 1. فتح الموقع محلياً

ببساطة، افتح ملف `index.html` في متصفح الويب:

```bash
# إذا كنت في مجلد المشروع
open index.html  # على macOS
start index.html # على Windows
xdg-open index.html # على Linux
```

### 2. استخدام خادم محلي (موصى به)

لتجربة أفضل، استخدم خادم ويب محلي:

```bash
# باستخدام Python
python -m http.server 8000

# أو باستخدام Node.js
npx http-server

# ثم افتح المتصفح على
# http://localhost:8000
```

## الخطوط المستخدمة

### TechmimArabic
خط عربي حديث وأنيق يستخدم في معظم النصوص:
- **Book**: للنص العادي
- **Bold**: للعناوين والنصوص المهمة

### ClashDisplay
خط إنجليزي عصري يستخدم للشعار والعناوين المميزة:
- **Bold**: للشعار والعناوين البارزة
